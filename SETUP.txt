UNITED DELHI SETUP

1. Frontend
   In the project directory:
   npm install
   npx expo start

2. Backend
   From the server directory:
   npm ci
   npm run check
   npm start

3. Backend environment
   Set DATABASE_URL and DTC_API_KEY in the server environment.
   Never put either secret in frontend source or the mobile bundle.

4. Current hosted backend
   The current backend is hosted on Wasmer.
   Service root: ./server
   Install command: npm ci
   Build command: leave empty
   Start command: npm start
   PORT: 3000
   Health endpoint: /health
   Readiness endpoint: /ready
   API base URL: https://united-delhi.wasmer.app

   Required environment variables:
   - DTC_REALTIME_RELAY_URL
   - DTC_REALTIME_RELAY_SECRET
   - DTC_API_KEY (private fallback)
   - DATABASE_URL

5. DTC realtime data
   Request API access through:
   https://otd.delhi.gov.in/data/realtime/
   The authorised key belongs only on the backend.

6. Static GTFS data
   The repository currently uses a pinned derived GTFS snapshot; refresh it when
   current official OTD static data is verified against live route IDs.
