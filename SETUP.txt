UNITED DELHI SETUP

1. In the project directory:
   npm install
   npm start

2. Mobile:
   npx expo start

3. Backend on Render:
   Create a Web Service using the /server directory.
   Build command: npm install
   Start command: npm start
   Add DTC_API_KEY as a Render environment variable.

4. DTC data:
   Request access through https://otd.delhi.gov.in/data/realtime/
   Obtain the authorised key and required static GTFS data through OTD.

5. Do not put DTC_API_KEY in App.tsx, GitHub, or the mobile bundle.
