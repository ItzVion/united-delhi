UNITED DELHI SETUP

1. Frontend
   In the project directory:
   npm install
   npx expo start

2. Backend
   From the server directory:
   npm ci
   npm run check
   npm start

3. Backend environment
   Set DATABASE_URL and TRANSPORT_STACK_API_KEY in the server environment.
   Never put either secret in frontend source or the mobile bundle.

4. Current hosted backend
   Provider: Render
   Service: https://united-delhi.onrender.com
   Service root: ./server
   Build command: npm ci
   Start command: npm start
   Health endpoint: https://united-delhi.onrender.com/health
   API base URL: https://united-delhi.onrender.com

   Required environment variables:
   - TRANSPORT_STACK_API_KEY
   - DATABASE_URL
   - APP_ORIGINS
   - TRANSPORT_STACK_REALTIME_URL (optional; defaults to the approved Transport Stack endpoint)
5. Static GTFS data
   The repository uses its pinned GTFS snapshot unless a newer compatible source is
   verified against the realtime route IDs.
