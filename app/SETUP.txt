UNITED DELHI — DEVELOPMENT AND DEPLOYMENT

CURRENT PRODUCTION
- Website: https://united-delhi.vercel.app (Vercel, root directory web/)
- API: https://united-delhi-api.onrender.com (Render, root directory server/)
- PostgreSQL: Neon, database neondb
- Git branch: main
- Render auto-deploy is disabled. Backend deployments are triggered by the static-data workflow after its verification step.
- Vercel handles the web project through its Git integration.

STATIC TRANSIT NETWORK
- Android and web both read bus and Metro network data from Neon.
- The reviewed DTC GTFS archive is committed at server/data/delhi_buses_static_gtfs_v1.zip.
- Its pinned SHA-256 is b5940afdaf6154880ec5652fd3e8465dd9183b68477c7c71a287685e0ef91ff8.
- The Static GTFS integrity and deploy gate checks the production data on a 48-hour cadence. A daily scheduled gate checks whether 48 hours have elapsed; skipped gates do not change the last successful verification marker.
- A manual workflow dispatch runs the check immediately. A push to main does not trigger this workflow.
- The importer validates the archive and live route-ID coverage, snapshots the previous static tables, imports within a transaction, and verifies persisted row fingerprints before commit.
- If Neon already matches the archive, the importer exits without replacing data.
- Do not use Render Shell or the retired browser uploader for static imports.
- The historical review of this archive measured 947 matches among 996 distinct realtime route IDs (95.08%). This was a sample at the time of review, not a guarantee of current coverage.
- The supplied Metro feed calendar ended 31 December 2025. Treat it as topology-only until a current authoritative calendar/timetable is available; journey durations remain estimates.

LIVE VEHICLE FEED
- Delhi OTD GTFS-Realtime supplies live vehicle positions.
- OTD_API_KEY is private and belongs only in the Render backend environment. Never include it in the Android app, website bundle, repository, or chat.
