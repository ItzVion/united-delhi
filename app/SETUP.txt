UNITED DELHI — DEVELOPMENT AND DEPLOYMENT

Repository folders
- app/     Expo React Native app and local Android APK builder
- web/     Vite/React website; Vercel root directory
- server/  Express backend and tests
- legal/   Legal and third-party notices

Android app
  cd app
  npm ci
  npm run typecheck
  npm test
  npx expo start

Local Windows APK (no cloud build):
  npm run build:apk

Requirements: Node 22, JDK 17, Android SDK/platform-tools and PowerShell.

Website
  cd web
  npm ci
  npm run dev

The current VPS API base URL is https://ud-api.mangotyping.fun. Temporary Render API base URL: https://united-delhi-api.onrender.com. Update app/src/config.ts, web/src/api.ts deployment configuration, and web/vercel.json only after the Render service is live and verified.

Vercel settings:
- Root Directory: web
- Include files outside root directory: Off
- Framework: Vite
- Install Command: npm install
- Build Command: npm run build
- Output Directory: dist
- The Vercel "Skip deployments when there are no changes to the root directory or its dependencies" setting is enabled. Keep it enabled so server-only commits do not rebuild the website.

Backend development
  cd server
  npm ci
  npm run check
  npm test
  npm start

Production architecture
- Website: Vercel with its existing native Git integration.
- API and PostgreSQL: Ubuntu/Debian VPS; the public API hostname is https://ud-api.mangotyping.fun.
- Backend auto-deploy timer: disabled by default. Keep it disabled unless separately reviewed and intentionally enabled.
- Android builds: local/manual only. Do not use EAS, GitHub Actions, or paid build services.

The current app build and website configurations use the VPS API hostname above. See server/deploy/SETUP.txt for operational notes; do not enable its VPS auto-deploy timer as part of routine source changes.

VPS environment variables
- DATABASE_URL (PostgreSQL connection string for the VPS database)
- TRANSPORT_STACK_API_KEY
- APP_ORIGINS (include https://united-delhi.vercel.app)
- PORT=10000
- TRANSPORT_STACK_REALTIME_URL (optional; defaults to the approved Transport Stack endpoint)

Keep DATABASE_URL and TRANSPORT_STACK_API_KEY only in /etc/united-delhi/server.env on the VPS. Never commit these values or add them to web/ or app/.

Vehicle colours
Only a valid upstream per-vehicle serviceColor is shown as the bus colour. If the live feed does not provide one, the marker stays neutral and is labelled unknown. Do not infer physical livery from route colours, vehicle type or registration prefix.
