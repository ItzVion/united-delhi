UNITED DELHI — DEVELOPMENT AND DEPLOYMENT

Current production
- Website: https://united-delhi.vercel.app (Vercel, root directory web/)
- API: https://united-delhi-api.onrender.com (Render, root directory server/)
- PostgreSQL: Neon, database neondb
- GitHub branch: main only
- GitHub Actions is manual-only. Routine deploys use Render and Vercel integrations.

Static transit network
- Android and web both read bus and Metro network data from Neon.
- Static GTFS data is loaded manually with one-shot commands from the Render Shell. The backend does not expose a browser file upload or public admin loading endpoint.
- The DTC loader validates the archive, route labels, references, route-stop links and recent live-route ID coverage. It creates hash-named snapshots and replaces the tables inside one database transaction.
- Keep GTFS ZIPs out of the repository except for the short deployment used for a data load. Remove them from the repository immediately after the load and deploy the clean tree.
- The reviewed DTC feed contains 2,554 routes and 6,812 stops. It matched 947 of 996 distinct live route IDs (95.08%) in the measured sample; 49 remain unmatched. The loader warns below 98% and refuses below 90%.
- The supplied Metro feed calendar ended 31 December 2025. It may only be loaded for topology; Metro journey durations remain estimates until a current timetable is supplied.

Live vehicle feed
- Delhi OTD GTFS-Realtime is used for live vehicle positions.
- OTD access requires an authorised private key. The backend reads OTD_API_KEY and sends it only to the official endpoint. Keep it in Render secrets only.

Android app
  cd app
  npm ci
  npm run typecheck
  npm test
  npx expo start

Local Windows APK
  npm run build:apk
Requirements: Node 22, JDK 17, Android SDK/platform-tools and PowerShell. Prefer local APK builds; no EAS or GitHub Actions build is required.

Website
  cd web
  npm ci
  npm run dev
Vite, Vercel and Android configurations use https://united-delhi-api.onrender.com.

Vercel settings
- Root Directory: web
- Framework: Vite
- Install Command: npm ci
- Build Command: npm run build
- Output Directory: dist

Backend
  cd server
  npm ci
  npm run check
  npm test
  npm start

Render environment
- DATABASE_URL
- OTD_API_KEY
- APP_ORIGINS=https://united-delhi.vercel.app

Security
Never commit DATABASE_URL or OTD_API_KEY. Use only the backend's private environment for these values.
