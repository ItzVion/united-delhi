UNITED DELHI — DEVELOPMENT AND DEPLOYMENT

Current production
- Website: https://united-delhi.vercel.app (Vercel, root directory web/)
- API: https://united-delhi-api.onrender.com (Render, root directory server/)
- PostgreSQL: Neon, database neondb
- GitHub branch: main only
- GitHub Actions is manual-only. Routine deploys use Render and Vercel integrations.

Data and integrations
- Live bus vehicle positions: Delhi Open Transit Data (OTD) GTFS-Realtime protobuf feed.
- OTD access requires an authorised private key. The backend reads OTD_API_KEY and sends it only to the official OTD endpoint as its documented key query parameter. Keep the value in Render backend secrets; never in app/, web/, or GitHub.
- Trip planning: United Delhi's own multimodal route engine using routes, stops, route_stops, metro_routes, metro_stops and metro_route_stops in Neon. It does not require a separate planner API key.
- Search suggestions use United Delhi /api/search and /api/metro endpoints.
- Static bus and Metro network data is loaded into Neon separately from the live OTD vehicle feed. Metro timetable data currently supports network topology only; its older calendar must not be presented as a current timetable.

Android app
  cd app
  npm ci
  npm run typecheck
  npm test
  npx expo start

Local Windows APK
  npm run build:apk
Requirements: Node 22, JDK 17, Android SDK/platform-tools and PowerShell. Prefer local APK builds; no EAS or GitHub Actions build is required.

Website
  cd web
  npm ci
  npm run dev

Web Vite proxy, web/vercel.json and Android build profiles use https://united-delhi-api.onrender.com. app/src/config.ts accepts EXPO_PUBLIC_API_BASE_URL for an intentional override.

Vercel settings
- Root Directory: web
- Framework: Vite
- Install Command: npm ci
- Build Command: npm run build
- Output Directory: dist

Backend
  cd server
  npm ci
  npm run check
  npm test
  npm start

Render environment
- DATABASE_URL
- OTD_API_KEY (authorised OTD realtime access; backend only)
- APP_ORIGINS=https://united-delhi.vercel.app
- DTC_STATIC_URL and DTC_STATIC_SOURCE_KEY
- METRO_STATIC_URL and METRO_STATIC_SOURCE_KEY
- OTD_COLOR_FIELD is optional and should remain unset until an upstream extension is verified.

Live feed setup
The OTD documentation specifies /api/realtime/VehiclePositions.pb?key=YOUR_PRIVATE_KEY. To enable live buses, add your authorised OTD private key to Render as OTD_API_KEY. This is the only external API credential required by the current backend.

Security
Never commit DATABASE_URL or OTD_API_KEY. Both web and Android clients use only the public backend base URL. Keep all provider credentials in Render's secret environment.

Legacy VPS documents under server/deploy/ are optional historical migration procedures; keep their timers disabled while production runs on Render.
