UNITED DELHI — DEVELOPMENT AND DEPLOYMENT

Repository folders
- app/     Expo React Native app and local Android APK builder
- web/     Vite/React website; Vercel root directory
- server/  Express backend and tests
- legal/   Legal and third-party notices

Current production architecture (verified 28 October 2026)
- Website: Vercel, https://united-delhi.vercel.app
- API: Render, https://united-delhi-api.onrender.com
- PostgreSQL: Neon (Singapore)
- Transport Stack has two independent backend credentials: TRANSPORT_STACK_API_KEY for live GTFS-RT vehicle positions and TRANSPORT_STACK_PLANNER_API_KEY for Multimodal Journey Planner requests.
- Both credentials and DATABASE_URL belong only in the Render backend environment. Never commit them or bundle them into web/ or app/.
- GitHub Actions CI is manual-only to avoid consuming Actions minutes. Render and Vercel deploy from main through their existing integrations.

Android app
  cd app
  npm ci
  npm run typecheck
  npm test
  npx expo start

Local Windows APK (no cloud build):
  npm run build:apk

Requirements: Node 22, JDK 17, Android SDK/platform-tools and PowerShell. Local APK building remains the preferred path; no EAS or GitHub Actions build is required.

Website
  cd web
  npm ci
  npm run dev

The Vite development proxy, web/Vercel API rewrite and Android build profiles must target https://united-delhi-api.onrender.com. app/src/config.ts uses the same default and accepts EXPO_PUBLIC_API_BASE_URL for an intentional override.

Vercel settings
- Root Directory: web
- Framework: Vite
- Install Command: npm ci
- Build Command: npm run build
- Output Directory: dist
- Keep the existing setting that skips builds when no files under web/ or its dependencies changed.

Backend development
  cd server
  npm ci
  npm run check
  npm test
  npm start

Render environment variables
- DATABASE_URL
- TRANSPORT_STACK_API_KEY (live GTFS-RT feed)
- TRANSPORT_STACK_PLANNER_API_KEY (Multimodal Journey Planner)
- TRANSPORT_STACK_REALTIME_URL
- APP_ORIGINS=https://united-delhi.vercel.app
- DTC_STATIC_URL and DTC_STATIC_SOURCE_KEY
- METRO_STATIC_URL and METRO_STATIC_SOURCE_KEY
- METRO_ALLOW_EXPIRED_CALENDAR=true is currently used only for Metro line/station connectivity from the older feed. Do not represent its timetable as current.

Live-data caveat
The current Render deployment has a working database connection and imported transit tables, but Transport Stack has been returning HTTP 401 for the live GTFS-RT key currently configured. Rotate that key with Transport Stack and update TRANSPORT_STACK_API_KEY in Render before expecting live bus positions. The separate planner key must not be placed in that variable.

Legacy VPS runbooks
The files under server/deploy/VPS-* describe an optional, inactive VPS migration path. They are not the current production architecture. Keep VPS auto-deploy timers disabled unless intentionally migrating back and verifying that deployment independently.

Vehicle colours
Only a valid upstream per-vehicle serviceColor or a reviewed livery record is treated as physical-colour evidence. Route/category/display colours are not claims about physical paint.
