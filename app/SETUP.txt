UNITED DELHI — DEVELOPMENT AND DEPLOYMENT

Repository folders
- app/     Expo React Native app and local Android APK builder
- web/     Vite/React website; Vercel root directory
- server/  Express backend and tests
- legal/   Legal and third-party notices

Android app
  cd app
  npm ci
  npm run typecheck
  npm test
  npx expo start

Local Windows APK (no cloud build):
  npm run build:apk

Requirements: Node 22, JDK 17, Android SDK/platform-tools and PowerShell.

Website
  cd web
  npm install
  npm run dev

Vercel settings:
- Root Directory: web
- Include files outside root directory: Off
- Framework: Vite
- Install Command: npm install
- Build Command: npm run build
- Output Directory: dist
- Enable "Skip deployments when there are no changes to the root directory or its dependencies" so server-only commits do not rebuild the website.

Backend development
  cd server
  npm ci
  npm run check
  npm test
  npm start

Production architecture target
- Website: Vercel
- Database: Neon PostgreSQL
- Backend: Ubuntu/Debian VPS running Node.js 22 with systemd
- Automatic backend deployment: GitHub Actions, path-filtered to server/**, with a 20-second quiet-period debounce
- Legacy Render service: remains running as a fallback while the VPS is provisioned; its repository blueprint now sets autoDeploy to false to avoid duplicate Render builds.

VPS deployment is intentionally disabled until the VPS has been provisioned, the server environment configured and HTTPS/API routing ready. See server/deploy/SETUP.txt. Do not set the VPS_DEPLOY_ENABLED repository variable until that setup is complete.

Until the VPS has a public HTTPS API hostname and has been tested, the app and website continue using the existing Render API:
  https://united-delhi-api.onrender.com

VPS environment variables
- DATABASE_URL (Neon connection string)
- TRANSPORT_STACK_API_KEY
- APP_ORIGINS (include https://united-delhi.vercel.app)
- PORT=10000
- TRANSPORT_STACK_REALTIME_URL (optional; defaults to the approved Transport Stack endpoint)

Keep DATABASE_URL and TRANSPORT_STACK_API_KEY only in /etc/united-delhi/server.env on the VPS. Never commit these values or add them to web/ or app/.

Vehicle colours
Only a valid upstream per-vehicle serviceColor is shown as the bus colour. If the live feed does not provide one, the marker stays neutral and is labelled unknown. Do not infer physical livery from route colours, vehicle type or registration prefix.
