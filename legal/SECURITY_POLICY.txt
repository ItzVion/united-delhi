# Security Policy

## Reporting a vulnerability

Please do not publish credentials, API keys, database URLs, or a working exploit in a public issue.

For a suspected security vulnerability in United Delhi, use a private GitHub security report if the repository enables GitHub Security Advisories. Otherwise, email **vion4712@gmail.com** with the subject **Security Report — United Delhi**. Do not include secrets in the initial report.

## Secrets

The following values must remain server-side and must never be committed:

- `TRANSPORT_STACK_API_KEY` (live vehicle positions)
- `TRANSPORT_STACK_PLANNER_API_KEY` (multimodal trip planning)
- `DATABASE_URL`

The mobile app and website receive only the public API base URL. The Transport Stack realtime API key is used only by the backend relay and must never be bundled into client apps.

## Scope

Security-sensitive changes should be tested with:

- frontend typecheck and tests
- backend syntax checks
- dependency audit
- database migration checks
- Android build validation where native configuration changes are involved
