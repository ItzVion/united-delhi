UNITED DELHI — LEGACY VPS BUILD AND AUTO-DEPLOYMENT RUNBOOK

CURRENT PRODUCTION WARNING
- The active production architecture is Vercel + Render + Neon. This file describes an optional, inactive VPS migration path only.
- Do not enable the VPS updater, change the frontend API host, or run cleanup/rebuild steps as routine maintenance.

ARCHITECTURE
- Website remains hosted on Vercel, but this VPS runs the web build and uploads prebuilt output to Vercel.
- Backend API runs on this Ubuntu/Debian VPS as the unprivileged united-delhi service user.
- PostgreSQL is local to this VPS: database united_delhi, role united_delhi_app.
- Optional VPS API hostname: https://ud-api.mangotyping.fun through Cloudflare Tunnel to http://localhost:10000.
- Adminer hostname: https://ud-db.mangotyping.fun through Cloudflare Tunnel to http://127.0.0.1:18080; protect it with Cloudflare Access for your own email.
- GTFS archives live at /opt/united-delhi/data/dtc-static.zip and /opt/united-delhi/data/metro-static.zip, outside code releases.

DEPLOYMENT AUTOMATION
GitHub Actions is manual-only and is not used for routine builds. The active production path uses Render's main-branch auto-deploy and Vercel's native Git integration. The optional VPS flow fetches origin/main only if its systemd timer is explicitly enabled; it must remain disabled in the current setup.
Vercel's Git integration can independently build source on main unless its Ignored Build Step is configured after a successful VPS prebuilt deployment. See the supplied AutoBuild Kit instructions.

ONE-TIME VPS KIT
Use the separately provided United-Delhi-VPS-Rebuild-Kit.zip. Upload it to /root/United-Delhi-VPS-Rebuild-Kit.zip with Termius SFTP, then run:
  sudo -i
  mkdir -p /root/ud-rebuild-kit
  unzip -oq /root/United-Delhi-VPS-Rebuild-Kit.zip -d /root/ud-rebuild-kit
  bash /root/ud-rebuild-kit/United-Delhi-VPS-Rebuild-Kit/install.sh
The installer removes only United Delhi deployment code/service artifacts, preserves PostgreSQL, /etc/united-delhi, /opt/united-delhi/data, backups and Cloudflare Tunnel configuration, installs base packages and Node.js 22, and creates a read-only GitHub deploy key. It does not restore/reset/migrate PostgreSQL, uninstall packages, change firewall rules, or alter cloudflared. After adding the printed key to GitHub with write access OFF, follow README-FIRST.txt for cloning and first backend verification. Android SDK/builds are intentionally not installed or enabled by default on the 3 GB RAM VPS.

GITHUB READ-ONLY ACCESS
Add the printed public key to https://github.com/ItzVion/united-delhi/settings/keys as a deploy key with write access unchecked. Then clone main:
  runuser -u uddeploy -- env HOME=/home/uddeploy USER=uddeploy LOGNAME=uddeploy git clone --branch main git@github.com:ItzVion/united-delhi.git /opt/united-delhi/repo
The deploy key is outbound, read-only access for the VPS to fetch the private repo. No GitHub Actions runner accesses this VPS.

LOCAL DATABASE AND SECRETS
The local DB was restored from a verified Neon SQL backup. Keep Neon and /root/united-delhi-backups/neon-before-migration-20261013.sql until cutover is verified.
- /etc/united-delhi/server.env: root:united-delhi, mode 0640.
- /etc/united-delhi/deploy.env: root:uddeploy, mode 0640.
- DATABASE_URL must point to postgresql://united_delhi_app:<password>@127.0.0.1:5432/united_delhi.
- If deliberately deploying this optional VPS, set `OTD_API_KEY` in `/etc/united-delhi/server.env` to an authorised Delhi OTD private key. Keep it root-owned and never commit it.
- Set VERCEL_TOKEN, VERCEL_ORG_ID and VERCEL_PROJECT_ID in deploy.env for Vercel CLI prebuilt deployments. Do not share the token.
- Do not run server/sql/001_reset_and_schema.sql; it is a disabled legacy destructive reset and raises an exception.

RUN ONE BUILD CYCLE
After the read-only repo key and local env files are configured, run one manual update cycle first. Only after reviewing its logs should you set AUTODEPLOY_ENABLED=1 in deploy.env, then run:
  systemctl start united-delhi-autodeploy.service
  journalctl -u united-delhi-autodeploy.service -n 200 --no-pager
The first pass fetches main, runs backend checks/tests, activates the backend only if its local /health and /api/status database checks pass, and runs a Vercel CLI prebuilt deploy only if WEB_DEPLOY_ENABLED=1 and Vercel settings are present. Android builds are opt-in and require ANDROID_BUILD_ENABLED=1 explicitly; they can exhaust RAM on a small VPS. Vercel native Git integration remains independent and is not disabled by this script. APKs are saved under /opt/united-delhi/artifacts/united-delhi-<commit-prefix>.apk.

ENABLE AUTOMATIC FETCH
After the first manual pass is good, run:
  systemctl enable --now united-delhi-autodeploy.timer
  systemctl list-timers united-delhi-autodeploy.timer
It polls main roughly every two minutes. A changed server/ directory triggers a tested/rollback-safe backend deploy; changed web/ triggers a Vercel prebuilt build/deploy from the VPS; changed app/ triggers an APK build only when ANDROID_BUILD_ENABLED=1 is explicitly set. On this 3 GB RAM VPS, keep Android builds disabled until capacity and swap behaviour have been checked. Failed component phases remain unmarked and retry on later timer runs.

VERCEL GIT INTEGRATION NOTE
After the first successful VPS prebuilt deployment, you may configure Vercel Project Settings -> Git -> Ignored Build Step to skip source builds for main:
  if [ "$VERCEL_GIT_COMMIT_REF" = "main" ]; then exit 0; else exit 1; fi
Vercel treats exit code 0 as skip. The VPS's Vercel CLI prebuilt deployment is independent of Git-triggered builds. Confirm in the Vercel UI before relying on it.

CURRENT API TARGETS
Current production remains Vercel + Render + Neon; the active API is https://united-delhi-api.onrender.com. This legacy VPS runbook does not change the app's API target. The optional VPS hostname above is only for a deliberate migration. If you intentionally migrate, set OTD_API_KEY in the backend environment and keep it private.
Keep PostgreSQL port 5432 private; never expose it publicly. Do not enable UFW without confirming SSH rules. Do not expose Adminer without Cloudflare Access. A local APK is a testing artifact unless a production upload keystore is securely configured.


RECOVERY SAFETY NOTE
- The legacy server/sql/001_reset_and_schema.sql has been neutralized; it now raises an exception instead of deleting tables.
- Read server/deploy/DATABASE-RECOVERY.md and server/deploy/VPS-REBUILD.md before database recovery or VPS rebuild.
